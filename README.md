# Portfolio
A repo for my project portfolio that demostrate my skill set. Each project has a README within its directory that goes into more detail about the project.

## Banish - A Rust Procedural Macro DSL
Banish is a declarative DSL embedded in Rust for building rule-based state machines. Instead of hand-writing state indexes, loop control, and fixed-point logic, you declare states and rules. Banish compiles them down to plain, zero-overhead Rust at compile time. Full compile-time validation, span-accurate error messages, and no runtime dependencies.
Featured in This Week in Rust.

Active project repo here: https://github.com/LoganFlaherty/banish

## FFT-Based Ocean Dynamics Simulation - Python
A physically informed ocean wave simulation built on Fast Fourier Transform techniques. Wave behavior is parameterized by wind velocity, direction, and time scaling, producing realistic dynamic surface motion. Multi-resolution grid computations are optimized for visual fidelity, with frame-based output rendered through Matplotlib for analysis and validation.

https://github.com/LoganFlaherty/portfolio/tree/main/Ocean%20FFT%20Sim

## Stock Price Time-Series Model - Python ML Pipeline
An end-to-end machine learning pipeline for short-horizon equity price prediction. Pulls live market data via a RESTful API from TastyTrade, cleans and engineers features from noisy time-series data, and trains a Gradient Boosting Regression model. Achieved roughly 1% normalized price error and 52% directional accuracy on held-out validation windows.

https://github.com/LoganFlaherty/portfolio/tree/main/Orb

## Protein Infection Predictive Modeling and Analysis
This project explores techniques for modeling and predicting processes on network graphs using R 4.3.3. It applies nearest-neighbor methods, Markov Random Fields (MRF), and kernel regression to a protein-protein interaction dataset.

https://github.com/LoganFlaherty/portfolio/tree/main/Predictive%20Modeling%20and%20Analysis%20of%20Processes%20On%20Network%20Graphs
